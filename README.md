## [span_12](start_span)🚀 المميزات الرئيسية للـنظام[span_12](end_span)

* **[span_13](start_span)🎛️ لوحة تحكم مركزية:** متابعة جميع الصيدليات الخمس من مكان واحد في الوقت الفعلي، مع إحصائيات لحظية وتنبيهات ذكية[span_13](end_span).
* **[span_14](start_span)💰 تتبع المبيعات:** سجل كامل ومفصل لكل عملية بيع، مع تصنيف حسب الصيدلية والكاشير والوقت[span_14](end_span).
* **[span_15](start_span)📊 تقارير شاملة:** كشوفات يومية وأسبوعية وشهرية، مع جرد سنوي كامل وتقارير الأرباح والخسائر[span_15](end_span).
* **[span_16](start_span)🔔 إشعارات تلقائية:** ارسال المبيعات اليومية إلى التليجرام والواتساب والإيميل تلقائياً في الوقت الذي تختاره[span_16](end_span).
* **[span_17](start_span)🧾 سندات القبض والصرف:** إصدار وحفظ سندات القبض والصرف مع طباعة احترافية وأرشفة كاملة[span_17](end_span).
* **[span_18](start_span)🏢 حسابات المجهزين:** إدارة شاملة لحسابات المجهزين والشركات الموردة، مع تتبع المستحقات والمدفوعات[span_18](end_span).
* **[span_19](start_span)📚 مكتبة 5000 دواء:** قاعدة بيانات جاهزة بـ 5000 صنف من الأدوية الأكثر طلباً في السوق العراقي[span_19](end_span).
* **[span_20](start_span)🔒 صلاحيات متعددة:** حسابات منفصلة بصلاحيات مختلفة للمالك، المحاسب، الكاشير، ومدير الصيدلية[span_20](end_span).
